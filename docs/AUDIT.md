# 原页面审阅与本仓库改进

审阅日期：2026-10-31。上游：[Biuapha/LLM-Analysis](https://github.com/Biuapha/LLM-Analysis)，基线提交 `06166dbbf9cd2dc0cd3119f4563cc8a46da489cf`。

## 已修复的计算问题

1. **SLO 与 MTP 产出假设耦合。** 上游用 ITL 目标 / TPOT 目标设置平均接受量，使放宽服务目标同时改变 workload。本仓库将平均产出作为独立输入，并限定在实际验证宽度和输出长度范围内；阈值只筛选 batch 候选。
2. **校准周期均值被当作尾部时延。** 平均周期耗时不能直接证明最坏上下文仍满足时延约束。修复后区分均值校准与解析推算的末上下文时延，并保留适用范围提示。

代码位置、公式、证据与回归测试见 [技术审查报告](TECHNICAL_AUDIT.md)。这些修复提高估算口径的一致性，不构成实测性能提升声明。

## 已实施的阅读与维护优化

| 原有问题 | 本仓库处理 |
| --- | --- |
| 固定 1600×960 SVG 按屏幕高度缩小，文字较密，小屏难读 | 默认可读比例，画布横纵滚动；提供缩放、100% 和适应窗口 |
| 算子与 Shape 较多，定位主要依靠目视 | 当前图内搜索、高亮和逐项跳转 |
| 页签键盘焦点与快捷入口不足 | 页签方向键 / Home / End，焦点可见，全局快捷键避开输入控件 |
| 计算器设置难以复现 | 浏览器本地保存、带版本号的配置链接、显式恢复默认参数 |
| 共享参数可能携带无效值 | 输入字段白名单、格式和长度限制、模型与选项校验 |
| 单个 HTML 不便确认修改后是否回归 | 独立增强模块，Node 原生测试，JSON / 脚本校验，GitHub Actions |
| 项目入口缺少使用说明与来源说明 | README、上游 fork 链接、技术审查与局限记录 |
| 多个“计算依据”链接指向未随上游发布的文件 | 新增数据依据页，直接读取真实内嵌数据，支持五类数据切换和 JSON 下载 |

## 仍需实测验证的内容

- 各硬件的真实算力利用率、HBM 带宽、通信重叠与路由不均衡。
- MTP / DSpark 的接受分布与末上下文时延；单个平均接受量不足以描述尾延迟。
- Cache 分配的具体布局、量化元数据和运行时额外副本，随软件版本变化。
- 图内引用的快照、源码 SHA 和校准数据来自上游资料，不能把本次页面审阅等同于重跑这些实验。

原页面已经提供来源固定、实测范围说明和解析模型。这些信息被保留；本仓库没有把估算包装成新的 benchmark。
